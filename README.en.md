# Project 15: Gradient Descent and Deep Learning

This repository contains the complete implementation of an artificial neural network (Multilayer Perceptron), developed *from scratch* in Python. The goal of this project is to identify and classify handwritten characters from the EMNIST database, relying exclusively on the fundamental mathematics of gradient descent and backpropagation, without using high-level Machine Learning libraries (such as TensorFlow or PyTorch).

## Key Features

* **Theoretical Modeling:** Strict mathematical implementation of forward propagation (*Feedforward*) and error backpropagation via the *Chain Rule*.
* **Algorithmic Optimization:** Full vectorization of matrix calculations using `NumPy` to leverage CPU SIMD architecture, eliminating software loops and drastically reducing execution times.
* **Advanced Training:** Comparison and implementation of several optimization algorithms. Use of Mini-Batch gradient descent coupled with Momentum to ensure fast and stable convergence.
* **Preprocessing Pipeline (Scenario):** Standalone image processing module (Gaussian Blur, Dynamic Otsu Thresholding, Padding Normalization) converting a raw image into a usable vector input signal.

## Installation and Prerequisites

### 1. Dependencies

The project requires a Python 3.x environment and the following standard libraries:

```bash
pip install numpy Pillow matplotlib

```

(Note: Pillow is used for image acquisition in the Scenario pipeline, matplotlib for visualizing loss curves).

### 2. Cloning the Repository

```bash
git clone [https://github.com/WebyPanda/Projet-Descente-Gradient-et-DeepLearning.git](https://github.com/WebyPanda/Projet-Descente-Gradient-et-DeepLearning.git)
cd Projet-Descente-Gradient-et-DeepLearning

```

### 3. Downloading the Dataset (EMNIST)

Due to its large size, the EMNIST database is not versioned in this repository. An automation script is provided to retrieve it from the official NIST servers.
Run the following command at the root of the project:

```Bash
python download_emnist.py

```

The script will automatically create a `gzip/` directory containing the files required to train the algorithm.

## Experimental Results

To avoid information bottleneck phenomena on the EMNIST Balanced dataset (47 classes: digits, uppercase and lowercase letters), the final architecture chosen features two hidden layers of size [512, 256].

Tuned synaptic parameters: > $5.4 \times 10^5$ weights and biases

Training method: Mini-Batch Stochastic Gradient Descent (batch size of 50)

Final accuracy rate: 85.2% generalization accuracy. (On a subset restricted to digits only, accuracy exceeds 96%)
